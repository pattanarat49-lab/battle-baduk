# Baduk Battle

เกมหมากล้อม (โกะ / บาดุก) บนเว็บ เล่นกับตัวละคร AI 8 คน ตั้งแต่ 15 คิวถึง 1 ดั้งโปร
AI ใช้เครือข่าย KataGo (g170e-b10c128) รันในเบราว์เซอร์ของผู้เล่นผ่าน TensorFlow.js ไม่ต้องมีเซิร์ฟเวอร์

- `index.html` หน้าเกม (สร้างจาก `src/` ด้วย `src/build.py`)
- `b10.json`, `b10.bin` น้ำหนักเครือข่าย (fp16)
- `tf.min.js` สำรองไว้เผื่อโหลด TensorFlow.js จาก CDN ไม่ได้
- `chars/` รูปตัวละคร
